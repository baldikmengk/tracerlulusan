Impor status alumni dari Excel

Cara termudah: klik Unduh daftar alumni (Excel), isi kolom Status dan Domisili (Dalam DIY / Luar DIY) di Excel, lalu unggah kembali di sini. Daftar yang diunduh mengikuti filter di bawah. Kolom file: NISN, Nama, TahunLulus, Status, Domisili. Siswa dicocokkan lewat NISN; bila NISN kosong, lewat Nama + TahunLulus. Status dan Domisili wajib terisi di semua baris; bila ada yang kosong, impor tidak bisa dilakukan. Status yang boleh: Melanjutkan Pendidikan, Bekerja, Berwirausaha, Mengikuti Pendidikan Nonformal/Pelatihan, Belum Bekerja. Di file Excel yang diunduh, kolom Status dan Domisili berupa pilihan (dropdown) dan tidak bisa diisi di luar pilihan.

Isian yang belum ditekan Simpan akan hilang saat pindah halaman atau mengubah filter.

Alur: pilih file, klik Periksa file dan baca laporannya (baris bermasalah beserta alasannya), lalu klik Impor sekarang bila sudah sesuai.

1. Impor data siswa

File Excel (.xlsx) dengan kolom: Sekolah, TahunLulus, NISN, Nama (opsional: NPSN, JK, Kota, Telepon). Siswa dengan NISN yang sudah ada ditolak sebagai duplikat.

2. Impor akun operator sekolah

Kolom: Username, Password, Sekolah (opsional: NPSN). Sebaiknya isi NPSN agar pencocokan sekolah akurat. Hapus file Excel setelah diimpor karena berisi password.

3. Impor rekap jumlah lulusan (data dinas)

Kolom: Jenjang, Nama Sekolah, NPSN, Program Keahlian/Jurusan, Tahun, L (Laki-laki), P (Perempuan), Jumlah. Mengimpor ulang akan mengganti seluruh rekap lama.

Pratinjau di bawah inilah yang dicetak atau diunduh. Di dialog cetak, pilih "Simpan sebagai PDF" untuk membuat file PDF.
